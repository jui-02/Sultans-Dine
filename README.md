# 🍽️ Sultan’s Dine – A Taste of Tradition & Excellence

This is a university project designed and developed by **Joynob Aktar Jui** as part of the Web Development Essentials course at **Daffodil International University**.

---

## 📖 About the Project

This website is built to represent the brand identity of **Sultan’s Dine**, a traditional Bangladeshi restaurant known for its signature dishes and warm hospitality. The **About Us** page is a key section that highlights the origin, mission, and vision of the business.

---

## 🛠️ Features

- 📄 Clean and structured HTML5
- 🎨 Stylish and responsive CSS3 layout
- 🧾 Well-organized content with mission and features
- 🖼️ High-quality image section
- ✅ Mobile and desktop responsive design

---

## 💡 Technologies Used

- HTML5
- CSS3 (Flexbox & Media Queries)
- Font Awesome Icons
